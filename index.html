S.A.I.N.T.

Network intrusion detection system that classifies traffic flows across five attack categories — and uses an LLM agent to explain why each alert fired, in plain English.

Research and educational project. Built on the NSL-KDD benchmark dataset — not hardened for production network defense.

Detection model

Each connection is represented by the 41-feature NSL-KDD traffic-flow schema — basic connection properties, content features, and two windows of time-based statistics.

Basic          duration, protocol_type, service, flag, src_bytes, dst_bytes, ...
Content        hot, num_failed_logins, logged_in, root_shell, su_attempted, ...
Time-based     count, srv_count, serror_rate, same_srv_rate, ...      (last 2 s, same host)
Host-based     dst_host_count, dst_host_srv_count, dst_host_serror_rate, ...  (last 100 connections)

Architecture

The classifier is one component of a pipeline — the reasoning agent and dashboard are what turn a score into something an analyst can act on.

model/classifier.py

Traffic-flow classifier over the 41-feature schema, producing a category and confidence per connection.

agent/reasoning.py

Reasoning layer that correlates signals across connections rather than judging each in isolation.

agent/explainer.py

Attributes each alert to the specific features that drove it, so a decision can be audited.

agent/llm_reporter.py

Turns a structured detection into a readable incident narrative for an analyst.

api/routes.py

Flask service exposing detection endpoints, backed by Redis for state and streaming.

dashboard/app.py

Live Plotly dashboard of traffic, alerts, and category breakdowns.

Run it

Containerized with Redis; scripts/replay.py streams the dataset back through the stack to simulate live traffic.

git clone https://github.com/abdeltaehass/S.A.I.N.T.
cd S.A.I.N.T.
docker compose up            # API + Redis + dashboard

python scripts/train.py      # train the classifier
python scripts/replay.py     # replay traffic through the live pipeline
